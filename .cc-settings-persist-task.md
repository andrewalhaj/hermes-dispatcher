ROOT CAUSE (already diagnosed — trust this):
Shell.tsx PanelView is a `switch` that returns a different component per tab, so switching tabs UNMOUNTS the panel and destroys its React-local useState. On return, Settings remounts fresh and its useEffect re-seeds from the LAST-SAVED config.yaml — so any pick the user didn't click "Save" on is lost. Also several controls (theme, assistant name, default workspace, most behavior toggles) are never sent to the backend even on Save, and accent lives only in Shell state so it dies on a full page reload.
